# TCL Google TV, Android 14 (SDK 34), MediaTek. Tested on a TCL Smart TV Pro (2.4 GB RAM), 2026-10.
# Close relatives (check with debloat/scan.sh first): other TCL Google TV sets on Android 12-14.
#
# Format: "[safe]", "[unused]" or "[ask]" starts a tier; one package per line, a note after it; "#" comments.
# Every package is disabled for user 0 only (pm disable-user), never uninstalled, and restore.sh turns it back on.
#
#   [safe]    ads, promos, tracking and telemetry. Nothing you use stops working (tested on the TV above).
#   [unused]  safe if you don't use the feature named in the note (tested on the TV above).
#   [ask]     a real choice, or not yet tested on this model. Never disabled without a yes for that package.
